# File map

- `docker-compose.yml`: registry images, startup dependencies, ports and volumes.
- `.env.example`: image/version and host-port configuration template.
- `scripts/install.sh`, `scripts/install.ps1`: clone and download installation/update paths.
- `docker/Dockerfile`, `docker/Dockerfile.dockerignore`: image build contract for an external source checkout.
- `.github/workflows/docker-publish.yml`: release/manual multi-platform publishing.
- `README.md`, `LICENSE`, `AGENTS.md`: usage, license and contributor instructions.
- `.workflow/`: plan, decisions and incremental file knowledge.
